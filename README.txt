# 📄 Log Analyzer

## Descripción

**Log Analyzer** es un proyecto desarrollado en Python con el objetivo de aprender programación aplicada a situaciones reales de soporte técnico e ingeniería de software.

El proyecto consiste en analizar archivos de logs, identificar eventos importantes, generar reportes y evolucionar progresivamente incorporando buenas prácticas de desarrollo.

Actualmente el proyecto se encuentra en desarrollo y cada versión agrega nuevas funcionalidades siguiendo un proceso similar al utilizado en proyectos profesionales.

---

## Objetivos

* Aprender Python mediante un proyecto práctico.
* Automatizar el análisis de archivos de log.
* Aplicar buenas prácticas de programación.
* Utilizar Git y GitHub para el control de versiones.
* Desarrollar habilidades propias de la ingeniería de software.
